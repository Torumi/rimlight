# Security policy

## Supported versions

Security fixes go into the latest stable release line (as a patch release) and into the
current pre-release lines. Older stable lines are not patched; please update.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/Torumi/rimlight/security/advisories/new).
Only the maintainers can see the report.

Include what you found, how to reproduce it, and its impact. rimlight is maintained in spare
time: expect an acknowledgement within two weeks. We will keep you updated, agree on disclosure
timing with you, and credit you in the advisory unless you prefer otherwise.

In scope: the rimlight application and CLI, the Linux udev rule, and the release builds.
Bugs in the strip's firmware or the vendor app are out of scope.
